# Predictions from Sustainability Agent

## 1. Product/UX Agent Prediction

I predict the Product/UX agent recommended **keeping the custom shell**, primarily because VS Code chrome would actively confuse users. The central editor pane in any IDE framework assumes a 2D text editor -- when the user instead sees a WebGL canvas rendering 3D glyph grids, every piece of surrounding VS Code-style UI (minimap, breadcrumbs, gutter, tab close buttons that imply "files open in an editor") creates a mental model mismatch. The agent likely argued that the 3D agent windows vision -- where AI agent output grows dynamically in three-dimensional space -- has no analog in any existing IDE's UX vocabulary, and forcing it into a framework's panel/view system would constrain the interaction design rather than enhance it. They probably conceded that a command palette (Cmd+Shift+P) is the one piece of IDE UX worth adopting, but as a custom implementation rather than importing Monaco's.

## 2. Engineering Agent Prediction

I predict the Engineering agent recommended **keeping the custom shell**, with strong emphasis on architectural incompatibility. Their core argument likely centered on the fact that every candidate framework (Theia, code-server, OpenVSCode Server) assumes Monaco as the editor surface, and replacing Monaco with a WebGL canvas is not a supported integration path -- it means fighting the framework's core abstraction rather than using it. They probably quantified the build system impact: the current project has zero build steps and serves native ES modules via a Python HTTP server, while any framework integration would require webpack/esbuild, potentially Electron-adjacent tooling, and hundreds of transitive dependencies. On the WebSocket/TUI command mapping, they likely noted that the existing `WorkerBridge` + custom WebSocket relay is simpler and more direct than wiring through a framework's extension host or terminal adapter. They probably estimated the integration at 3-6 weeks of work to achieve feature parity with what already exists in 2,487 lines, with ongoing maintenance cost that exceeds the custom shell's carrying cost within the first year.
