# Predictions: encoding

## plumbing
They likely concluded that harfbuzzjs should be vendored as a single WASM blob loaded via `fetch()` + `WebAssembly.instantiate()`, with the JS wrapper kept minimal and imported as an ES module. For workers, I expect they proposed that WASM gets loaded once on the main thread and the compiled `WebAssembly.Module` is transferred to workers via `postMessage()` (since `Module` is transferable/structured-clonable), avoiding redundant network fetches and compilation per worker. Font delivery is probably a single `.ttf` fetch, parsed once by HarfBuzz into an `hb_face`/`hb_font` pair, with workers receiving either the raw font `ArrayBuffer` (to create their own `hb_font` instances) or only the shaped glyph results from the main thread -- I suspect they went with the former since shaping is the part that benefits most from parallelism and each worker needs its own `hb_font` handle.

## rendering
They likely concluded that GlyphRenderer's fragment shader gets replaced with a Slug-style winding-number evaluator: for each fragment, look up the glyph's band data via `texelFetch` on `glyphMapTexture`, find the relevant horizontal and vertical bands from the `bandTexture`, iterate the referenced curves from `curveTexture`, compute algebraic winding number contributions from each quadratic bezier, and use the combined winding count (odd/even or nonzero) to determine inside/outside coverage. I predict they specified that atlas generation (`GlyphAtlas.js`) and bitmap sampling are fully removed rather than kept as a fallback, since the project convention is no backward-compat shims. The vertex shader changes are probably minimal -- they still use instanced quads, but now pass `glyphId` (replacing `instanceCodepoint` UV-based atlas lookup) as a flat varying so the fragment shader can index into the glyphMapTexture. They likely noted that the three new DataTextures (curve, band, glyphMap) become uniforms on the material, and the existing highlight texture and picking system remain unchanged since those operate at the instance level, not the glyph-shape level.
