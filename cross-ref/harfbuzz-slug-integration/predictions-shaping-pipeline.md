# Predictions: shaping-pipeline

## shader-rendering

I expect shader-rendering concluded that porting Slug's cubic Bezier evaluation into the fragment shader is feasible under GLSL ES 3.0 but carries significant ALU cost per fragment, likely recommending band/curve textures as DataTextures (RGBA Float or RGBA16F) to avoid blowing the fragment budget on complex glyphs. They probably flagged that WebGL 2 lacks compute shaders and SSBO, so curve data must flow through textures or UBOs, and that the instanced lookup from `gl_InstanceID` to per-glyph curve ranges requires a small indirection texture (offset + count per glyph). Antialiasing was likely identified as the hardest part -- Slug's analytic AA depends on exact coverage computation that is expensive per-texel, so they probably proposed a hybrid where simple glyphs use the bitmap atlas path and only high-zoom or large glyphs switch to the SDF/Slug path, or recommended signed distance approximation rather than full exact-coverage Slug rendering.

## migration-integration

I expect migration-integration produced a detailed per-phase file change matrix listing every file touched across all three phases (shaping, rendering, integration), flagging `src/workers/builders/index.js` and `GlyphAtlas.js` as the highest-risk files since both my shaping changes and the rendering changes converge there. They likely identified font bundling in the Go binary as straightforward (add `.ttf` and `.wasm` to the `//go:embed` directive and serve them as static assets, ~2-4MB size increase) but flagged WASM MIME type handling as a potential gotcha. Their testing strategy probably centers on visual regression (screenshot comparison of rendered text before/after) since there is no test runner, plus a manual rendering test page under `examples/`. Risk assessment likely called out the "big bang" danger of changing both shaping and rendering simultaneously, recommending that Phase A (HarfBuzz shaping with bitmap atlas) ship and stabilize before Phase B (Slug fragment shader) begins, with a LOD/hybrid fallback keeping the bitmap path alive permanently for distant/small text where vector rendering is wasted GPU.
