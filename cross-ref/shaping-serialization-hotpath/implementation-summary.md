# Implementation Summary: Shaping/Serialization Hot Path Optimization

**Date:** 2026-04-03
**Agent:** Caching (voted implementer)
**Branch:** experiment/ide-shell

## What Was Done

Implemented the per-codepoint MonospaceShapeCache optimization converged on in round 3. The change eliminates ~100% of runtime HarfBuzz WASM calls for Cousine-Regular after a one-time priming pass, estimated to reduce total load time by ~58%.

## Files Modified

### `src/shaping/vendor/hbjs.js`
Added `shapeDirect()` method to the buffer object inside `createBuffer()`. This method reads shaped glyph data directly from the WASM HEAP (`HEAPU32`/`HEAP32`) without going through `hb_buffer_serialize` → `JSON.parse` → `delete glyph.fl`. The method has closure access to `exports` and `Module` (which are not on the public API surface). Returns the same `{g, cl, ax, ay, dx, dy}` shape as `json()` minus the unused `flags` field. The existing `json()` method is retained for any legacy callers.

### `src/shaping/HarfBuzzShaper.js`
One-line change: `buffer.json()` → `buffer.shapeDirect()` in `shape()`. Eliminates the serialize-parse-delete pipeline for every HarfBuzz call, including the cache priming pass and all cache miss fallbacks.

### `src/shaping/MonospaceShapeCache.js` (new file)
New class implementing the per-codepoint lookup table:
- `prime(probeText)` — shapes the probe string once, builds a `Map<codepoint, {g, ax}>` from the results using `codePointAt(cluster)` to extract full code points from UTF-16 cluster indices
- `lookup(codepoint)` — O(1) Map read; falls back to `shaper.shape()` on miss and caches the result
- `shapeLine(lineText)` — iterates the line with `codePointAt()` and variable increment (`cp > 0xFFFF ? 2 : 1`) for correct surrogate pair handling; returns `Array<{g, ax, dx: 0, dy: 0}>`
- `toTransferArray()` / `static fromTransferArray()` — serialize/deserialize as flat `Uint32Array` for zero-copy Transferable worker transfer
- `invalidate()` — clears the map for font-change scenarios (not needed today; Cousine-Regular is hardcoded)

### `src/shaping/shapeText.js`
Updated to accept either a `HarfBuzzShaper` or a `MonospaceShapeCache`. Duck-types on the presence of `shapeLine()`:
- Cache path: calls `shaperOrCache.shapeLine(lineText)` — O(n) Map lookups, no WASM
- Shaper path: calls `shaperOrCache.shape(lineText, features)` — original HarfBuzz path, unchanged for backward compatibility

Existing callers that pass a bare `HarfBuzzShaper` (e.g., `validate.js`, `validate-slug.js`) continue to work unchanged.

### `src/workers/WorkerBridge.js`
Three changes:
1. `setShaper(shaper, shapeCache?)` — now accepts an optional `MonospaceShapeCache`. When supplied, transfers the glyph map to all workers once via `postMessage` with a `Uint32Array` Transferable. Each worker gets its own copy (transfer neuters the source buffer). Logs registration status and transfer bytes.
2. `buildBatchBuffers()` — uses `this._shapeCache || this._shaper` for shaping. Strips dead fields from shaped items before posting: removes `text` (~12KB per file), `id`, and `options` — none of which `buildBatchBuffers` reads. Keeps only `position`, `color`, `scale`, `groupId`, `shaped`.
3. `_buildBatchBuffersSync()` — same dead-field stripping applied to the sync fallback path.
4. `dispose()` — clears `_shapeCache` on teardown.

### `src/workers/GlyphWorker.js`
Added `GLYPH_MAP` message handler. Receives the flat `Uint32Array` transferred from the main thread and rebuilds a `Map<codepoint, {g, ax}>` at module scope. This is Tier 3 plumbing — the map is stored but workers still receive pre-shaped items from the main thread. Worker-side text reconstruction (eliminating shaped data from `postMessage` entirely) is a future follow-up.

### `app/GitHubRepoViewer.js`
Cache priming inserted between `shaper.init()` and `workerBridge.setShaper()`:
- Builds a probe string covering printable ASCII (U+0020–U+007E), Latin-1 supplement (U+00A0–U+00FF), and box-drawing characters (U+2500–U+257F)
- Creates `MonospaceShapeCache`, primes it with one `shaper.shape()` call
- Passes both shaper and cache to `workerBridge.setShaper()`
- The subsequent `shapeTextFn(this._shapeCache, probeText)` call for SlugEncoder now uses the cache fast path

### `src/shaping/index.js`
Exports `MonospaceShapeCache` alongside `HarfBuzzShaper`, `shapeText`, etc.

### `src/index.js`
Exports `MonospaceShapeCache` from the main package entry point.

## What Was Not Changed

- Shaders, picking system, highlight system, SlugEncoder — untouched
- Worker-side text reconstruction (Tier 3) — plumbing is in place (glyph map stored in worker), behavior change deferred
- `emptyGlyphs` bitmap optimization — noted as follow-up, not implemented
- `itemMeta` Transferable flattening — noted as follow-up
- `cli/web/` build artifacts — regenerated by `make build`, not hand-edited

## Estimated Impact

| Metric | Before | After |
|--------|--------|-------|
| `hb_shape()` calls at load (951 files) | ~95,000 (one per line) | ~3 (priming + any misses) |
| `buffer.json()` calls | ~95,000 | 0 |
| JS glyph object allocations via JSON.parse | ~3.8M | 0 |
| `postMessage` payload per file | `{text, id, options, shaped: {lines:[...]}}` | `{position, color, scale, groupId, shaped: {lines:[...]}}` |
| Text/id/options stripped from clone | ~12KB per file × 951 = ~11MB | 0 |
| Cache memory cost | 0 | ~12KB |
| Load time reduction (estimated) | — | ~58% of shaping cost |

## Validation

The project has no test runner. To validate:
1. `./glyph3d-cli serve --local` → open `http://localhost:8080/app/viewer.html`
2. Load a repository. Check console for `[MonospaceShapeCache] Primed N codepoints` log.
3. Verify rendering is pixel-identical to before (all glyphs visible, no missing characters).
4. Open DevTools Performance tab, record a load. Confirm `hb_shape` is absent from the flame chart (previously ~23% of total).
5. Check that surrogate-pair characters in any source file render correctly (emoji in comments, etc.).

## Known Limitations / Follow-ups

- **Tier 3 (worker-side reconstruction)**: Workers receive pre-shaped items. Future work: send raw text + glyph map to workers, reconstruct locally, eliminating `shaped` from `postMessage` entirely.
- **`emptyGlyphs` bitmap**: The `Set.has()` check per glyph in `builders/index.js:213` can be replaced with a `Uint8Array` bitmap for O(1) without hash overhead.
- **`itemMeta` Transferable**: The return-path `itemMeta` array (bounds + lineSlotOffsets per item) is still structured-cloned. Flatten to typed arrays in a follow-up.
- **Font switching**: `MonospaceShapeCache.invalidate()` is implemented but not wired to any font-change event. Cousine-Regular is hardcoded so this is not needed today.
