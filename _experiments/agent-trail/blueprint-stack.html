Agent Trail — blueprint stack

Each turn is one blueprint sheet; its inputs · actions · outputs are organized into lanes on the sheet, with actions tethered to the data they produced. New turns stack in depth — append front or back, like a chat thread's top/bottom. You read the front sheet; the history recedes behind it, edges and title-blocks peeking. Fly to a sheet to read it.
